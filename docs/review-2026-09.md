## 数据源、年份与更新结论

当前使用的就业来源快照没有记录原始下载日期。已为实际输入增加 `data/employment_sources.json`：URL、Git 快照提交、SHA-256、审核日期、线上检查结果。**审核日期不是数据发布日期，也不是成功刷新日期。**

2026-09-15 实测：六国 SDMX 请求全部返回 HTTP 403；ILOSTAT bulk 目录、印度 bulk 文件和公开 API 说明端点也返回 403。不能由此判断官方没有更新，也不能声称仓库快照已是最新。

## 代码维护与发布

- 活跃应用是纯静态 HTML/Canvas + 预先生成的 JSON，没有在线模型调用或后端。美国 BLS 缓存 HTML、CSV、score.py 等均属于历史资产，不参与六国构建；其模型名称、提示词和旧数据不应视为本产品当前指标依据。没有在本次 review 中调用付费评分 API。
- Python 锁文件补齐 openpyxl 3.1.5 / et-xmlfile 2.0.0，其他原有包版本保持。旧解析器输出补齐下游需要的 slug。
- 发布 Actions 更新到审查时官方最新稳定版本并固定提交 SHA：checkout 7.0.1、configure-pages 6.0.0、upload-pages-artifact 5.0.0、deploy-pages 5.0.1；验证使用 setup-uv 10.1.0、uv 0.12.11。来源为各官方仓库的 release 与 tag commit。本轮未实际触发生产发布，生产环境兼容性还要由合并后的 Pages 工作流确认。
- 原发布流程最近一次 `master` 运行成功，但它只上传静态文件，不证明数据计算正确。新流程先校验输入哈希、数据维度、关键统计与离线重建一致性，再发布。
- 新增只读更新检查脚本 `scripts/check_source_updates.py`，按观测比较数据及元数据，输出 `unchanged` / `review_required` / `unverified`。403 返回非零退出状态，绝不当作“无更新”；脚本不会修改已审核快照。
- 页面新增数据来源/限制页，修正缺失数据与零值的展示，检查 HTTP 状态和数据 schema，加载失败时禁用图层按钮。

## 验证与边界

16 项数据测试覆盖印度取列、父组性别去重、未分类分母、断点与跨调查拒绝、U/缺失值、重复行/单位、官方技能映射、旧构建覆盖保护以及 GenAI 映射；增加离线重建检查。所有 127 行 PLFS 记录与官方 PDF 的 9 个数值列独立核验。浏览器验证覆盖六国四图层、男女汇总、低覆盖提示、暂停趋势、缺失值、GenAI 明细及加载失败。

仍未解决的源数据限制：印度三位绝对人数的混合口径、六国实时数据更新的访问障碍、国家间年龄/调查期/就业定义的完整对照，以及缺少各国四位职业就业权重和实际 AI 使用数据。页面已披露这些边界；不能把修复后的地图称为六国最新官方全量统计，也不能用其估计 AI 导致的实际失业。
